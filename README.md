# Weather-App
A sleek, responsive web app that fetches real-time weather data for any city using the OpenWeatherMap API. It also dynamically updates the background with beautiful images from Unsplash based on the searched location.

## Features
- Fetches real-time weather information for any city.
- Displays temperature, humidity, wind speed, and weather description.
- Dynamically changes background using Unsplash API (optional enhancement).
- Clean and responsive UI design with loading indicator.
- Uses modern JavaScript and asynchronous API calls.

##  Technologies Used
- HTML5
- CSS3 (Flexbox and Responsive Design)
- JavaScript (ES6+)
- OpenWeatherMap API
- Unsplash API (optional)
